## Démarche

1. Lire `01-prerequis-techniques.pdf` et faire les installations.
2. Parcourir `04-enonces-exercices.pdf` et choisir un énoncé, ou décrire un cas personnel selon la même structure.
3. Remplir la fiche de cadrage (`exercices/fiche-cadrage-agent.docx`) et la faire valider avant de développer.
4. Ouvrir le dossier de l'énoncé dans `exercices/` :
    - `exercices/light/` : l'énoncé seul ;
    - `exercices/middle/<énoncé>/` : les documents prêts à l'emploi ;
    - `exercices/avance/<énoncé>/` : les outils et le serveur MCP de l'énoncé (E06 à E12, G01) ;
    - `exercices/n8n/` : la piste n8n.
